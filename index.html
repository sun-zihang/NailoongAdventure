奶龙冒险
Nailoong Adventure

一句话，从零生成一只会战斗的奶龙

在 Unity 中从零打造的 3D 冒险游戏 Demo：环境、战斗、任务、完整关卡流程，角色动画与视听效果全程程序化生成，不依赖任何外部美术 / 音频素材。

⭐ 在 GitHub 查看源码 ⬇ 下载 Windows 版
🐲

核心特性

全部由 Editor 脚本在首次打开工程时自动生成

🌍

程序化世界

海滩、森林、火山三大关卡地形与场景，由代码按关卡主题拼装生成。

⚔️

流畅战斗

普攻三连击、咕噜冲撞、泰山压顶、龙耀吐息、奶龙变色，技能环环相扣。

📜

任务系统

对话、收集、击退、救援等任务目标，由 LevelFlow 串联成完整流程。

🗺️

多关卡流程

奶黄海滩 → 奶油森林 → 焦糖火山，含三阶段 Boss 与通关结算。

🦴

程序化动画

自研骨骼系统 + 呼吸 / 尾巴延迟波浪 / 眨眼 / 挤压拉伸，过渡天然平滑。

🎵

视听效果

代码合成 WAV 音效与 BGM、粒子特效与 UI，零素材即可运行。

纯 C# · 可复现 · 开源 MIT

操作说明

键盘 + 鼠标即可畅玩

W A S D相机相对方向移动
空格跳跃（可二段跳）
鼠标移动环绕视角
鼠标左键普攻三连击（拍击 ×2 + 尾扫）
Shift咕噜冲撞（翻滚冲刺，期间无敌）
Q泰山压顶（跳起砸地，范围击飞）
F龙耀吐息（持续喷射星火）
R奶龙变色（减伤 50% + 提速）
E / ESC与 NPC 对话 / 开启传送门 · 暂停

想玩吗？拿源码，自己构建

本仓库只提交源代码（脚本 / Shader / 工程设置 / 文档）。克隆后用 Unity Hub 打开工程，首次导入后自动生成全部内容；点击 奶龙 / 构建 Windows 64 可执行程序（或双击 build.bat）即可打包出 Builds/Win64/NailoongAdventure.exe。
