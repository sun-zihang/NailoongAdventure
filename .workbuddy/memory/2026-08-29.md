## 重要教训（易踩坑）
- **Unity Hub 无 `--headless` CLI**（报 `bad option`），不能命令行装模块；只能从本地 `modules.json` 取 URL 下载后静默安装。
- **schtasks 省略 `/ru` 不等于 SYSTEM**，而是当前用户（未提权）；要提权需创建 `/rl HIGHEST` 任务，而这本身又需已提权令牌 → 死循环，只能由用户手动提权。
- **`schtasks /tr` 内嵌套引号会导致整条 bash 命令链静默死亡**（无输出、exit 1）。解决：用 8.3 短名（`C:\PROGRA~1`）消除路径空格，避免嵌套引号。
- **Bash 沙箱差异**：`curl -o` 写 `D:\Project` 失败（curl error 23），但 `cp` 写 `D:\Project` 成功；写 `%TEMP%` 两者皆可。大文件下载先落 Temp 再 cp 到 D 盘。
