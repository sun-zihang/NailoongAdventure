## 修复 WebGL 下奶龙身体不可见
- 问题：WebGL 构建后游戏中只有眼睛可见，身体和场景缺失。
- 根因：SkinnedMeshRenderer 的 m_AABB 在保存 prefab 时为 {0,0,0}，WebGL/IL2CPP 构建后运行时被视锥剔除。
- 修复：
  1. DragonFactory.Build 中显式设置 `smr.localBounds = mesh.bounds;` 并 `updateWhenOffscreen = true`。
  2. GameBuilder.PersistMeshes 中对所有 SkinnedMeshRenderer 设置 `localBounds` 与 `updateWhenOffscreen`，并 `EditorUtility.SetDirty`。
- 验证：重新全量重建后 Player_Nailoong.prefab 的 m_AABB 已恢复为正常值（center ≈ (0, 0.96, -0.37)，extent ≈ (0.66, 0.94, 0.98)）。

## 修复 WebGL wasm 加载失败
- 问题：访问生产域名时浏览器弹窗报错 `both async and sync fetching of the wasm failed`.
- 根因：`_headers` 中 `/game/*` 声明了 `Cross-Origin-Embedder-Policy: require-corp`，而 Cloudflare Pages 默认不给 `.unityweb` 文件添加 `Cross-Origin-Resource-Policy` 响应头，导致浏览器拦截 wasm/data 子资源。
- 修复：移除 `/game/*` 下的 COOP/COEP，保留 `/game/Build/*.unityweb` 的 `Cache-Control: public, max-age=300, no-transform`。
- 验证：新部署 `fee8cb4c` 已上线，生产域名 `nailoongadventure.pages.dev` 同步指向新版本；wasm 响应头不再含 COEP/COOP。
- GitHub 推送：当前网络多次连接 reset，待恢复后重试 push commit `6612fbe`.

## 优化 WebGL 加载速度
- 问题：用户反馈移动端打开游戏时加载条很慢。
- 根因：WebGL 资源总量约 16MB（data 8.4MB + wasm 7.3MB），且默认 Brotli 压缩后体积仍较大；同时 `_headers` 仅缓存 5 分钟，每次刷新都重复下载；loading 页无进度文案提示。
- 修复：
  1. `_headers`：将 `/game/Build/*.unityweb` 的 `Cache-Control` 从 `max-age=300` 延长至 `max-age=86400`，配合 Unity 已开启的 `webGLDataCaching` 大幅减少重复加载。
  2. `build-site.js`：在打包阶段向 `dist/game/index.html` 注入 `unity-loading-hint`，实时显示进度百分比与“首次约需 5-8MB，请耐心等待”提示。
- 验证：生产域名 `nailoongadventure.pages.dev` 已同步更新；wasm 响应头为 `Cache-Control: public, max-age=86400, no-transform`；线上 index.html 已包含 loading 提示。
- 注意：尝试直接修改 `ProjectSettings.asset` 的 `webGLCompressionFormat` 和 `managedStrippingLevel` 被 `GameBuilder.BuildWebGL` 运行时覆盖（代码已显式设置 `Brotli` 与 `ManagedStrippingLevel.Disabled`），实际构建产物已经是 Brotli 压缩后大小。
- GitHub：`main` 已推送至 `11fe7fa`。
